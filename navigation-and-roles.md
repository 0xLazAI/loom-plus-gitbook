# Navigation And Roles

Loom+ groups the sidebar by permission level so users can find operational work without scanning unrelated admin tools.

## User

Every team member sees:

- Collaboration: coordination issues and operational follow-up.
- Projects: project boards and missions.
- Wiki: knowledge bases, documents, and Ask Wiki.
- Schedule: calendar and meeting workflows.
- Agents: saved bot and group entrypoints for agent workflows.

## Admin

Admins also see:

- Members: team member management.
- Invitations: invite link creation and tracking.
- Access Token: MCP and CLI access tokens.
- Models: model configuration and testing.
- Logs: KB logs, MCP/CLI logs, Fireflies logs, and system logs in one tabbed page.

## Owner

Owners also see a separate Owner block:

- Team: team name, transfer, leave, and ownership controls.
- Google Meeting: Google Calendar OAuth, meeting management, and Fireflies setup.
- Agents: Coordinator Bot links, deployment provider, and bot environment setup.

The Team page does not duplicate member management. Members belong in Admin.

## System Admin

System Admins see a separate System Admin block:

- Platform-level teams.
- Platform-level users.
- System admin assignment.
- Owner invitation and platform controls.

System Admin access is intentionally separated from team Admin and Owner access.
