# Getting Started

This guide is for new team members joining Loom+ for agent collaboration work.

## Join A Team

1. Open the invite link sent by your team Admin or Owner.
2. Sign in with the Google account that received the invite.
3. Confirm the team invitation.
4. If you already belong to multiple teams, use the team switcher in the left sidebar.

## Bind Telegram

Telegram binding is required only if your team uses Telegram-based agent workflows.

1. Open `Profile`.
2. Find your Loom+ binding code.
3. Message the configured Loom+ Telegram bot.
4. Send `/bindloomid YOUR_CODE`.
5. Return to Loom+ and confirm the external account is connected.

## Daily Workflow

1. Open `Collaboration` to review coordination issues and decisions.
2. Open `Projects` to manage missions, owners, deadlines, and status changes.
3. Open `Wiki` to search team knowledge or ask a knowledge base.
4. Open `Schedule` to review upcoming meetings.
5. Use logs when a task, meeting ingestion, MCP call, or CLI action needs audit context.

## When To Ask An Admin

Ask an Admin or Owner if you need:

- A team invite.
- Access token creation.
- Model access.
- Google Meeting setup.
- Fireflies setup.
- Permission changes.
